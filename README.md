# python-para-soc

Estudos e scripts em Python aplicados à cibersegurança e ao trabalho de analista de SOC.

## Sobre

Sou estudante de Engenharia de Software e estou construindo minha base em Blue Team (SOC) e Python. Este repositório reúne o que vou praticando, do básico aos scripts de análise de logs.

## Scripts

| Script | O que faz |
|---|---|
| `scripts/ip_privado.py` | Pede um IP e diz se é privado, público ou loopback |

## Como usar

```bash
python3 scripts/ip_privado.py
```

Exemplo:

```
Escreva seu IP: 192.168.1.5
Privado
```
